# ORRERY / Interactive Solar System

Интерактивная модель солнечной системы в одном HTML-файле. Без сборки, без зависимостей.

## Что умеет

- Вращение сцены мышью или пальцем (drag), зум колесом
- Клик по планете открывает её карточку с данными
- Страницы: Система, Каталог, Наблюдения, Настройки
- Фокус на объекте прямо из каталога
- Управление временем: pause/play и шкала скорости
- Переключатели орбитальных следов, подписей и автовращения
- Адаптив: desktop, планшет, мобильный

## Запуск

Открой `index.html` в браузере. Всё.
